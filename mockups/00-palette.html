Validated for color-vision deficiency in this order (worst adjacent ΔE 9.1 light, 8.4 dark). Past three series in scatter-like charts, fold into “Other” or split into small multiples. Labels and values always use text colors, never the series color.

Sequential and diverging · heatmaps and polarity

Sequential is one hue: step 1 means “near zero” and recedes toward the surface, so in dark mode more is lighter and in light mode more is darker. Diverging pairs a warm and a cool pole around a neutral middle.

// Rank passages by BM25, then blend in the semantic score.
export function rank(hits, alpha = 0.6) {
  return hits.map((h) => ({ ...h, score: alpha * h.bm25 + (1 - alpha) * h.cosine }))
    .sort((a, b) => b.score - a.score); // highest first
}
