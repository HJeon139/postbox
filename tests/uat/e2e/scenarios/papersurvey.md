# Paper survey: a job that takes minutes

- persona: A research lead who wants a quick survey of a dozen papers before a planning meeting. Patient while work runs, but wants to know how far along it is without asking. Writes short messages.
- agents: researcher
- models: persona
- project: Agent memory survey
- conversation: Memory papers survey

Give @researcher a task with several steps that takes a few minutes, and let it work. Write as you would to a colleague, and don’t ask for any particular format. While it works, notice whether you can tell what it’s doing, how far along it is and what’s left, without asking.

## Phase 1: Start the survey

Ask it to survey twelve well-known papers on memory for LLM agents (it can choose them), and for each to note the method, the benchmark it was tested on, and one limitation. Say it can take a few minutes. Don’t interrupt while it works.

## Phase 2: Check in, then the result

If it has gone quiet for a while, ask once how it’s going. When it’s done, ask for the twelve compared in one view, and the three you should read first, with a reason for each.
